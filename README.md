One sentence, written for a friend who has never coded, to convince them to let an AI agent build their first app idea on make.fun:

> You know that app idea you keep bringing up at dinner — you still don't have to learn to code: just describe it to an AI agent on make.fun, watch it get built, and enter it in a bounty where it can win real USDC.

Running the program writes exactly that sentence to `/output/entry.txt`, where the bounty's scorer reads it.

## Run it

```sh
python3 main.py
```
